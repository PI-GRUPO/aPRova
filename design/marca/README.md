# Marca do aPRova

Arquivos exportados do Figma (arquivo XoNmZcGCx0oDwSk7RCWIy3, página Marca). Texto convertido em contorno: não depende da fonte instalada.

## Versões

| Arquivo | Uso |
|---|---|
| `logo-horizontal-*` | Padrão: cabeçalho do dashboard, landing page, slides |
| `logo-vertical-*` | Capa, tela de login, espaços quadrados |
| `logotipo-*` | Só o nome, quando o símbolo já aparece por perto |
| `simbolo-*` | Avatar, favicon grande, marca d'água |
| `icone-app-*` | Ícone do GitHub App, favicon, app |
| `simbolo-alternativo-fundo-escuro` | Alternativa "Ponto de verificação", não usar como principal |

`fundo-escuro` = desenho claro (#ECE9E2) para fundo escuro. `fundo-claro` = desenho escuro (#111214) para fundo claro.

## PNG

- `icone-app-*-{512,256,180,64,32,16}.png`: 512 para o GitHub App, 180 para apple-touch-icon, 32 e 16 para favicon
- Demais versões em `@4x`

## Cores e fontes

- Tinta #111214, papel #ECE9E2
- IBM Plex Sans (a, ova) e IBM Plex Mono SemiBold (PR)
