Nenhum PR de IA chega à main sem prova

PR: pedido para juntar uma mudança ao código principal. main: a versão oficial do código.

Código escrito por IA é testado num ambiente isolado, sem internet. Regras fixas decidem o risco, cada decisão é assinada, e risco alto espera uma pessoa.

Um caso real, do começo ao fim

O PR #6 do projeto de testes traz um teste que falha de propósito.

  1. A IA abre o pedido

    Um agente de IA abre o PR no GitHub, onde o código fica guardado.

    No PR #6 Um pedido que acrescenta um teste ao cálculo de frete.

    PI-GRUPO/aPRova-TESTES · PR #6

    Testa frete com peso zero

    Pede para juntar 6 commits à main

    go/frete/frete_test.go+7

    +

+  valor, err := Calcular(0, 100)

    Mais detalhes

    O GitHub avisa o aPRova por webhook, e cada versão do código (commit) ganha uma análise.

  2. Roda isolado, sem internet

    Os testes rodam numa caixa fechada, com permissões mínimas.

    No PR #6 10 testes passaram, 1 falhou.

    Sandbox · Go · sem internet

    Mais detalhes

    Sandbox em duas etapas: prepara com rede e testa com --network none, com usuário sem privilégio. Go, Python e Java.

  3. Regras fixas decidem

    Sete regras olham o que mudou; nenhuma IA participa.

    No PR #6 «Testes falharam»: risco alto.

    Nomes no código: falha_sandbox, dependencia_nova, segredo_versionado, configuracao_ci, area_sensivel, muitos_arquivos e codigo_sem_teste. A mesma mudança dá sempre o mesmo risco; sem nenhuma regra, o risco é baixo.

  4. O histórico pode baixar um nível

    Casos parecidos já aprovados podem baixar o risco um nível.

    Mais detalhes

    Desligado por padrão e registrado no recibo. Nunca sobe o risco nem baixa dois níveis. Testes falhando, biblioteca nova, senha no código e mudança na automação nunca baixam.

  7. Risco alto espera uma pessoa

    Quem tem permissão aprova pelo Slack, o chat da equipe, ou pelo GitHub.

    No PR #6 Aprovação pelo Slack, na apresentação.

    Mais detalhes

    Se algo passou, o aPRova prepara o comando; quem desfaz é uma pessoa.

    Mais detalhes

Além da decisão

Recursos de apoio. Nenhum muda o risco decidido pelas regras.

  • Desligado por padrão

    Alertas no GitHub

    Os motivos do risco aparecem como alertas na aba de segurança.

    Mais detalhes

    SARIF 2.1.0 enviado ao code scanning; liga com SARIF_LIGADO.

  • Desligado por padrão

    Saúde do sistema

    Números de uso e de saúde para quem opera, num endereço interno.

    Mais detalhes

    /metrics, /health/live e /health/ready; liga com METRICAS_ENDERECO.

  • Limites de uso

    60 análises por hora

    Por conta. Acima disso, o pedido espera na fila; nunca passa sem análise.

    Mais detalhes

    Teto por instalação em APROVA_TETO_ANALISES_POR_HORA; leitura pública de recibos limitada a 60 por minuto por IP.

  • Desligado por padrão

    Explicação em texto simples

    Uma IA descreve a decisão que as regras já tomaram.

    Mais detalhes

    Gemini, só no comentário do PR; liga com EXPLICACAO_LIGADA.

Ver como conferir

Comandos para conferir o recibo do PR #6 com OpenSSL 3:

$ jq -r .payload_base64    recibo.json | openssl base64 -d -A > payload.bin
$ jq -r .assinatura_base64 recibo.json | openssl base64 -d -A > assinatura.bin
$ CHAVE='Jlx6KQYEoJTm/atXMaj53IJHUfJxKEDtKrtqPWKsm1s='
$ { printf '302a300506032b6570032100' | xxd -r -p; printf '%s' "$CHAVE" | openssl base64 -d -A; } \
    | openssl pkey -pubin -inform DER -out chave-publica.pem
$ openssl pkeyutl -verify -pubin -inkey chave-publica.pem -rawin -in payload.bin -sigfile assinatura.bin
Signature Verified Successfully

No macOS, o openssl do sistema não confere Ed25519; o do Homebrew confere (brew install openssl@3). A chave é a da instância da demonstração.

O aPRova barra o código quebrado e deixa passar o certo?

Uma IA resolveu 21 exercícios, e cada solução passou pelo aPRova. Os testes originais diziam quais estavam certas.

Rodada 1: a IA podia rodar os testes (claude-sonnet-5). Rodada 2b: não podia (claude-haiku-4-5).

Limites: uma rodada por tarefa, só 4 quebradas, e a 2b mudou modelo e execução juntos. Relatório completo
